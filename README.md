# Kuritsu's dotfiles

## Dependencies

### Programs configured:
- hyprland
- hyprpaper
- hypridle
- hyprlock
- waybar
- wofi
- dunst
- foot
- btop

### Other dependencies
- hyprpicker (for the SUPER+k shortcut in hyprland)
- grim, slurp (for screensharing in hyprland and screenshot)
- wf-recorder (for screen recording shortcut)
- uwsm (to run hyprland)
- wl-clipboard (to copy screenshot when taken)
- nautilus (file-manager shortcut in hyprland)

## Installation

- Ensure all dependencies are installed and respective services running

### Any distro

There are 2 possible ways to install these dotfiles:
1. clone this repostiory somewhere and symlink all files to the correct destination (stow can be used)
2. simply clone this repository into your home directory (not recommended)
